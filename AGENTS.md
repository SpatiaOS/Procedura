# Procedura

For a request to build a 3D model through MCP, read
`.agents/skills/procedura/SKILL.md`. The current coding-agent session supplies
generation; the existing Procedura program owns all stages, geometry validation,
retries and completion. Follow the user's chosen model, launcher and scope.

For development, documentation, setup or maintenance requests, edit the necessary
code and run the relevant checks. Do not treat an MCP modelling run as permission
to change its frozen inputs, profile, gates or artifacts.

The direct API CLI and Studio remain available. MCP is an additional transport.
